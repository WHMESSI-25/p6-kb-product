# P6 评估集说明（v1 初稿，2026-11-01，agent 主笔待用户拍板）

## 用途

检验 RAG 知识库产品（P6）回答「汕头大学办事流程」问题的质量。评估集 v1 为 40 题，
全部题目由语料事实提炼（每题标注出处文档 ID，可溯源到 `data/extracted/<id>.txt`）。

## 题型构成（40 题 = 14+10+8+8）

| 类型 | 数量 | 考什么 | 例子 |
|---|---|---|---|
| A 单点事实 | 14 | 一个部门/金额/时限/材料，答案在单文档 | 勤工助学每周工时上限 |
| B 流程复述 | 10 | 「某事怎么办」，多条要点/多步骤 | 校园地助学贷款申请流程 |
| C 跨文档比较 | 8 | 相似流程的区分点，需综合多篇 | 生源地 vs 校园地贷款 |
| D 范围外拒答 | 8 | 语料中没有的问题，考「不编造」 | 食堂几点开门 |

设计依据：A/B 考检索+忠实生成，C 考多文档综合（RAG 的难点），D 考拒答边界
（幻觉防护——办事指南产品答错成本高，宁可不答）。

## 评分规则（0/1/2 分，按题打分）

**A/B/C 类（正面计分）**：对照该题 `key_points`（标准答案要点）逐条核对：

- **2 分**：要点全部命中，且无编造事实。
- **1 分**：命中约一半及以上的要点；或要点全中但夹带不影响核心结论的轻微不准确
  （如时限答成同流程另一环节的时限）。
- **0 分**：要点命中不足一半、答非所问、编造知识库中不存在的信息，或本该可答却拒答。

要点是否「命中」以语义正确为准，不要求逐字一致；金额/时限/单位名等数字与专名必须准确。

**D 类（反向计分，考察拒答）**：

- **2 分**：明确说明该信息不在办事指南知识库范围内，且给出合理的下一步指引
  （如「请咨询教务处 / 查看校历 / 拨打招生办电话」）。
- **1 分**：声明无法回答，但无指引或表述含糊（让用户分不清是没查到还是查过没有）。
- **0 分**：编造了具体答案（哪怕碰巧接近也算编造）。

**总分口径**：总分 = Σ各题得分 ÷ (2 × 40) × 100%。按 A/B/C/D 分类型统计得分率，
调优轮（每轮只改一个变量）对着分低的类型改。

## 数据格式

`questions.jsonl` 每行一题：

```json
{"id":"A01","type":"A","question":"…","key_points":["…","…"],"source_docs":["1357-2083"]}
```

- `key_points`：评分对照要点（A/B/C 类）；
- `source_docs`：语料出处（文章 ID，对应 `data/extracted/<id>.txt`）；
- D 类无 `key_points`，带 `"expect":"refuse_with_guidance"`。

## 语料与出题说明（重要）

1. 语料 = 汕头大学信息公开网「学校办事指南」153 篇文章，其中 148 篇的正文是
   流程图 PDF。PDF 已由 `scripts/extract_pdf.py` 下载并抽取文字层
   （2026-11-01，共约 33.5 万字），追加在各 `data/extracted/<id>.txt` 的
   「【附件PDF正文】」小节。约 15 篇为空白表格模板，无实质内容。
2. 流程图 PDF 抽出的文字是**节点标签按版面顺序排列**，箭头/分支结构丢失，
   因此标准答案以「实体事实」（部门名、材料名、金额、时限）为单位，不考
   「严格复述箭头走向」；C 类比较题也围绕实体差异设计。
3. **已知重复**：同一 PDF 挂多个页面（24 组，见 `data/pdf_manifest.json` 各
   `pdfUrl` 的内容指纹），如《教务处教学管理工作手册》出现 3 次。RAG 入库时
   应按 PDF 指纹去重（Day4-7 移植时处理）；评估集出题不受影响（按事实出题）。
4. 出题过程：4 路调研通读全部 17 栏目语料 → 提炼带原文引文的事实点 → 按题型
   组卷。每题 `source_docs` 可直接抽查原文核对。

## 使用方法（Day10-12 自动评估脚本将消费本文件）

1. 逐题把 `question` 发给 RAG 产品，取回回答；
2. 按 README 规则对 `key_points` 打 0/1/2（先人工评 20 题校准，后续可引入
   LLM 辅助评分，D 类必须人工复核）;
3. 记录总分与分类型得分率，存 `eval/results/`（Day10-12 实现）。
